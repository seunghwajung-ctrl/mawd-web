# 도입 문의 메일 발송 설정 안내 (대표용)

홈페이지 '도입하기' 양식에 문의가 들어오면 team.mawd@cyz.today로 메일이 오게 하는 설정입니다.
개발 지식 없이 순서대로 따라 하면 됩니다. 15분 정도 걸립니다.

전체 흐름: 방문자 → 마우드 사이트 서버(로봇 확인·입력 검사) → 이 Apps Script → team.mawd@cyz.today

## 준비물

- **팀 구글 계정**(메일을 보낼 계정)으로 로그인한 브라우저
- 다비가 알려 준 **공유 비밀값** 1개 (긴 무작위 문자열). 아래 2단계와 5단계에서 똑같이 씁니다. 채팅이나 메일 본문에 그대로 붙여 두지 말고, 받은 뒤 바로 지워 주세요.

## 1단계. 프로젝트 만들기

1. https://script.google.com 에 접속합니다.
2. 왼쪽 위 **새 프로젝트**를 누릅니다.
3. 왼쪽 위 '제목 없는 프로젝트'를 눌러 이름을 `MAWD 도입 문의`로 바꿉니다.
4. 편집기에 있는 `function myFunction() {}`을 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣습니다.
5. 디스크 모양 **저장** 버튼을 누릅니다.

## 2단계. 공유 비밀값 넣기

1. 왼쪽 톱니바퀴 **프로젝트 설정**을 누릅니다.
2. 맨 아래 **스크립트 속성** → **스크립트 속성 추가**를 누릅니다.
3. 속성: `SHARED_SECRET`, 값: 다비가 알려 준 공유 비밀값을 넣고 **스크립트 속성 저장**을 누릅니다.

## 3단계. 웹앱으로 배포하기

1. 오른쪽 위 파란 **배포** → **새 배포**를 누릅니다.
2. '유형 선택' 옆 톱니바퀴 → **웹 앱**을 고릅니다.
3. 다음처럼 설정합니다.
   - 설명: `도입 문의 v1`
   - 다음 사용자로서 실행: **나**(팀 구글 계정)
   - 액세스 권한이 있는 사용자: **모든 사용자**
     (사이트 서버가 로그인 없이 호출해야 해서 필요합니다. 공유 비밀값이 없으면 메일이 가지 않습니다.)
4. **배포**를 누릅니다.
5. '액세스 승인' 창이 뜨면 **액세스 승인** → 팀 구글 계정 선택 → '확인되지 않은 앱' 경고가 나오면 **고급** → **MAWD 도입 문의(으)로 이동** → **허용**을 누릅니다. 이 계정으로 메일을 보내도 되는지 묻는 것입니다.
6. 마지막 화면의 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

## 4단계. 웹 앱 URL을 다비에게 전달

복사한 URL을 다비에게 보내 주세요. 이 URL도 비밀처럼 다룹니다(공개 채널에 올리지 않기).

## 5단계. Vercel 환경변수 (다비가 하거나, 대표가 직접)

Vercel → `mawd-web` 프로젝트 → Settings → Environment Variables에서 아래 4개를 **Production과 Preview 모두**에 넣습니다.

| 이름 | 값 |
|---|---|
| `INQUIRY_APPS_SCRIPT_URL` | 3단계에서 복사한 웹 앱 URL |
| `INQUIRY_APPS_SCRIPT_SECRET` | 2단계에 넣은 공유 비밀값 |
| `RECAPTCHA_SECRET_KEY` | 다비가 발급한 reCAPTCHA 비밀 키 |
| `NEXT_PUBLIC_RECAPTCHA_SITE_KEY` | 다비가 발급한 reCAPTCHA 사이트 키(공개돼도 되는 값) |

넣은 뒤에는 분기를 다시 배포해야 반영됩니다(다비가 처리).

reCAPTCHA 키 발급(다비): 체크박스 방식으로 만들고, 도메인 목록에 `mawd.cyz.today`와 `vercel.app`(미리보기 주소용)을 **둘 다** 넣습니다.
`vercel.app`이 빠지면 미리보기에서 'Invalid domain' 오류가 떠서 6단계 시험을 할 수 없습니다.
'출처 확인(Verify the origin of reCAPTCHA solutions)' 설정은 켜 둔 상태(기본값)를 유지합니다.

## 6단계. 시험 문의 1건

1. 미리보기 주소의 `/inquiry`에서 양식을 채워 보냅니다.
2. '문의가 접수되었습니다'가 뜨고, team.mawd@cyz.today에 **[도입 문의]** 메일이 **1통** 오면 끝입니다.
3. 오지 않으면 Apps Script 왼쪽 **실행** 메뉴에서 오류 기록을 캡처해 다비에게 보내 주세요.

## 나중에 코드를 고쳐야 할 때

`Code.gs`를 바꾼 뒤 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 누르면 같은 URL이 유지됩니다.
**새 배포**를 누르면 URL이 바뀌니 주의하세요.

## 참고

- 하루 메일 발송 한도가 있습니다(무료 구글 계정 기준 하루 100통 내외, Workspace 계정은 더 많음). 문의 양식 규모로는 충분합니다.
- 이 스크립트는 메일만 보내고 시트·드라이브 등 다른 곳에 저장하지 않습니다. 중복 발송을 막으려고 문의 내용이 아닌 무작위 접수 번호만 10분 동안 Apps Script 캐시에 둡니다.
